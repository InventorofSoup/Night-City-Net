# Self-hosted interface fonts

These WOFF2 files replace the former live Google Fonts requests so Elflines Online and Trauma Team retain their intended typography during offline campaign use.

Families included:

- Cinzel
- Inter
- JetBrains Mono
- Barlow Condensed
- DM Mono
- Manrope

The fonts were obtained through the Google Fonts CSS service and are distributed under their respective open font licenses. Upstream family and license records are available from the [Google Fonts repository](https://github.com/google/fonts).

Only the Latin subsets and weights used by the sites are included.
